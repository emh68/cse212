# C# Data Structures Tutorial
Welcome to the C# Fundamentals Tutorial. This tutorial is not intended to be a comprehensive guide on all types of data structures; rather, it provides explanations and examples for the following three commonly used data structures:
* <ins>[Queue](/1-Queue.md)</ins>
* <ins>[Linked List](/2-linkedlist.md)</ins>
* <ins>[Tree](/3-Trees.md)</ins>

Each module contains a description and examples. At the end of each module, you will find a problem to solve on your own. You should only look at the solution after you have attempted to solve the problem first.
